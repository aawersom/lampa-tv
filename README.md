# lampa-tv

Small Lampa 3.x plugins for the owner's TV.

- `ru-torrents.js` — default torrent sort `RuSeeders` (nothing hidden, each release ranked on its own):
  Russian releases first, then the rest; inside: the film's own year first, then seeders (descending).
  The same torrent found by both parsers is shown once, with all its trackers and the larger seeders count.
